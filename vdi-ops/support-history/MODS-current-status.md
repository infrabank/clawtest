# MODS 현재 기술지원 상태 업데이트

업데이트 기준: 현우님 직접 확인

## 핵심 이슈 상태

| 항목 | 현재 상태 | 비고 |
|---|---|---|
| 방화벽 정책 변경 승인 추적 | 완료 | 기존 P1 후속 추적 종료 |
| ESXi 7대 관리 IP 이전 | 불가 | 기존 계획은 진행하지 않음 |
| 스토리지 운영방안 PM 회의 후속 | 완료 | SR014 후속 완료 |
| L08/L09 Storage vMotion | 완료 | 스토리지 운영 후속 작업 완료 |
| HW/SW 유지관리 비용 산정 | 완료 | SR012 완료 |
| Horizon GPU Pool 구성 | 완료 | GPU Pool 구성 완료 |
| Windows 11 업데이트/Recompose 계획 | 미완 | 계속 추적 필요 |
| VDI 대용량 통계 데이터 처리 성능 개선 | 보류 | SR006 보류 |
| 지역센터 IP 관리 체계 수립 | 미완 | 계속 추적 필요 |
| 제로클라이언트 vs 씬클라이언트 구매 검토 | 완료 | 검토 완료 |

## 현재 남은 주요 미완/보류

1. Windows 11 업데이트/Recompose 계획
2. 지역센터 IP 관리 체계 수립
3. VDI 대용량 통계 데이터 처리 성능 개선 — 보류
4. ESXi 7대 관리 IP 이전 — 불가로 정리

## 브리핑 시 반영 기준

- MODS를 여전히 최우선 관리 대상으로 보되, 완료된 항목을 진행 중으로 반복 보고하지 않는다.
- 방화벽 승인, 스토리지 PM 후속, Storage vMotion, 유지관리 비용 산정, GPU Pool, 씬/제로클라이언트 구매 검토는 완료로 간주한다.
- ESXi 관리 IP 이전은 미완이 아니라 **불가/취소 성격**으로 분류한다.
- VDI 대용량 통계 데이터 처리 성능 개선은 미완이 아니라 **보류**로 분류한다.
