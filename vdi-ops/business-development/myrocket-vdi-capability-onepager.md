# (주)마이로켓 VDI 기술지원 협력 소개서

> 공공기관 VDI/가상화 환경의 구축·운영·유지보수·장애대응을 지원하는 기술 파트너

## 1. 소개

**(주)마이로켓**은 세종권을 기반으로 공공기관 VDI 환경의 구축, 운영, 유지보수, 장애대응, 작업계획 및 산출물 작성을 지원합니다.

Citrix, Omnissa Horizon, VMware vSphere/ESXi/vCenter 기반 VDI 환경을 중심으로, SI/NI/총판사의 공공기관 사업에서 필요한 **VDI 전문 기술지원·현장지원·문서 산출물 작성**을 협력 형태로 수행합니다.

## 2. 주요 지원 범위

### VDI 운영/장애대응

- Omnissa Horizon / VMware Horizon 운영 점검
- Citrix Virtual Apps and Desktops 운영 점검
- 사용자 접속 장애, Agent 오류, UAG/Connection Server 이슈 분석
- 인증서 체인, 외부접속 경로, 방화벽 정책 연계 점검
- 정기점검 보고서, 장애보고서, 원인분석 보고서 작성

### VMware 가상화 인프라

- vSphere / ESXi / vCenter 기반 가상화 환경 점검
- vCenter/ESXi 업그레이드 및 마이그레이션 작업계획 수립
- vMotion / Storage vMotion / Cold Migration 작업 지원
- 스토리지 이관, Datastore 사용량, VM 리소스 검토
- 작업 전 사전점검, 롤백계획, 완료보고서 작성

### 공공기관 산출물 지원

- 제안서 기술범위 검토
- 작업계획서 / 변경작업 계획서
- 완료보고서 / 점검보고서
- 장애보고서 / RCA
- 운영 매뉴얼 / 인수인계 문서
- 고객 질의 답변서 / 기술검토 의견서

## 3. 협력 가능 형태

| 형태 | 내용 |
|---|---|
| 단기 현장지원 | 대전·세종·청주·천안·충남·충북권 현장 점검/작업 지원 |
| 2선 기술지원 | 기존 유지보수팀의 VDI/가상화 이슈 분석 지원 |
| 프로젝트 지원 | 구축, 업그레이드, 마이그레이션, 인증서 교체, 스토리지 이관 지원 |
| 산출물 지원 | 제안서, 작업계획서, 완료보고서, 장애보고서 작성 |
| 협력사 하도급 | 정보통신공사업 보유 SI/NI/총판사의 VDI 전문 파트너 역할 |

## 4. 대응 가능 지역

**우선 대응 지역**

- 세종
- 대전
- 청주
- 천안
- 충남
- 충북

서울 소재 SI/NI/총판사가 대전·세종·충청권 공공기관 사업을 수행하는 경우, 지역 현장지원 및 VDI/가상화 전문 기술지원 파트너로 협력 가능합니다.

## 5. 기술 키워드

- Citrix Virtual Apps and Desktops
- Omnissa Horizon / VMware Horizon
- Unified Access Gateway, Connection Server
- VMware vSphere, ESXi, vCenter
- vMotion, Storage vMotion, Cold Migration
- FSLogix, Golden Image, Recompose
- 인증서, 방화벽 정책, 접속 경로 점검
- 공공기관 정기점검, 장애대응, 산출물 작성

## 6. 협력 포지션

(주)마이로켓은 정보통신공사업 면허가 필요한 공고에 직접 투찰하기보다는, 정보통신공사업을 보유한 SI/NI/총판사의 **VDI·가상화 전문 기술지원 파트너**로 협력하는 형태를 지향합니다.

특히 공공기관 VDI 환경에서 발생하는 운영 이슈, 장애 분석, 작업계획 수립, 고객 보고 산출물 작성 영역에서 빠르게 투입 가능합니다.
