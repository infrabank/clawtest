# 현우봇 민감정보 저장/공유 기준

작성일: 2026-05-14

## 기본 원칙

현우봇은 현우님의 VDI 유지보수 업무를 돕기 위해 고객사 운영정보를 다룰 수 있으나, 외부 공유·Git 커밋·메일 발송 전에는 민감정보를 반드시 점검한다.

## 저장 위치별 기준

| 위치 | 허용 수준 | 원칙 |
|---|---|---|
| 현우봇 로컬 워크스페이스 | 상세 업무 메모 가능 | 외부 노출 금지. 이전 시 보안 채널 사용 |
| `maint/` private repo | 고객사별 운영 문서 가능 | private 유지 전제. public 전환/공유 전 마스킹 |
| `vdi-ops/` 로컬 문서 | 업무 템플릿/요약 중심 | IP/계정/담당자 직통 등은 최소화 |
| Google Sheets CRM | 협력사/영업 정보 중심 | 고객사 상세 인프라 정보 저장 금지 |
| 외부 메일/제안서 | 마스킹/요약만 | 고객사명, IP, 계정, 내부 구성, 담당자 연락처 제거 또는 승인 후 사용 |
| Manus/외부 AI | 비식별 정보만 | 고객사 실명/운영 IP/계정/장애 상세 로그는 전달 금지 |

## 민감정보 예시

- 고객사 내부 IP, 서버명, 계정명, 도메인명
- 담당자 휴대폰, 직통번호, 개인 이메일
- 방화벽 정책, 네트워크 대역, VPN/접속정보
- 장애 로그 원문, 보안 취약점 세부정보
- 견적 금액, 계약 조건, 라이선스 수량
- 공공기관 내부 일정 중 비공개 성격의 작업

## 마스킹 규칙

| 원본 | 외부 공유 예시 |
|---|---|
| 10.xxx.xxx.161 | 10.xxx.xxx.xxx 또는 AD 서버 1 |
| 홍길동 / 010-xxxx | 고객 담당자 또는 담당자 A |
| 특정 기관 내부망 상세 | 고객사 VDI 내부망 |
| 장애 로그 원문 | 주요 오류 코드/증상 요약 |

## 업무 처리 원칙

1. 고객사 세부정보가 포함된 자료는 외부 AI/Manus에 보내지 않는다.
2. 외부 제안서에는 고객명보다 “공공기관 VDI 유지보수 경험”처럼 범주로 표현한다.
3. Git 커밋 전에는 public/private 여부를 확인한다.
4. 메일 발송 전에는 수신자와 첨부파일에 민감정보가 없는지 확인한다.
5. 현우님이 명시적으로 승인한 경우에만 실명/상세정보를 외부 공유한다.

## 기본 운영 결정

- 협력사 CRM은 Google Sheets에 저장한다.
- 고객사 인프라 상세정보는 Google Sheets/Notion보다 로컬 문서 또는 private repo 중심으로 관리한다.
- 외부 공유용 산출물은 항상 마스킹 버전을 별도 생성한다.
