# Gmail 기반 VDI 업무 인박스 트리아지 규칙

## 목적

매일 또는 요청 시 Gmail을 조회해 VDI/공공기관/협력사 관련 메일을 분류하고, 현우님이 바로 처리할 수 있는 다음 행동으로 정리한다.

## 분류 카테고리

| 분류 | 설명 | 우선순위 |
|---|---|---:|
| 장애/긴급 | 장애, 접속불가, 지연, 시간동기화, 인증서 오류 등 | P1 |
| 정기점검 | 월간/분기 점검 일정, 점검표, 결과 회신 요청 | P2 |
| 작업/변경 | 방화벽, 인증서, 업그레이드, 재구성, 패치, 마이그레이션 | P2 |
| 고객 회신 필요 | 고객/협력사 질문, 확인 요청, 자료 요청 | P2 |
| 협력사/영업 | 콜드메일 회신, 미팅, 파트너 문의 | P3 |
| 계산서/행정 | 계산서 발행, 계약, 견적, 입찰 | P3 |
| 뉴스/학습 | AI/VDI/보안 뉴스레터, 벤더 공지 | P4 |
| 홍보/삭제 후보 | 단순 할인/광고/무관한 세일즈 | P5 |

## 출력 형식

### Gmail VDI 인박스 브리핑

1. **긴급/장애**
   - 메일 제목 / 발신자 / 고객사 / 필요한 다음 행동

2. **오늘 회신 필요**
   - 제목 / 회신 초안 필요 여부 / 자료 확인 필요 여부

3. **일정 등록/변경 필요**
   - 일정명 / 날짜 / 캘린더 반영 여부

4. **협력사/영업**
   - 업체 / 담당자 / 상태 / 후속 액션

5. **삭제 또는 보류 후보**
   - 제목 / 이유

## 기본 원칙

- 고객사 IP/담당자/환경정보는 외부 공유 전 마스킹한다.
- 애매한 건 임의 답장하지 않고 초안만 만든다.
- 장애/정기점검 메일은 maint 저장소와 vdi-ops 문서를 함께 확인한다.
