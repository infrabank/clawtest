# AI 뉴스 기반 실행 액션 — VDI 업무 자동화

작성일: 2026-05-15

## 오늘 선택한 액션

**VDI 유지보수 업무에서 반복되는 고객 메일 → SR/작업기록/보고서 초안 자동화 흐름을 우선 설계한다.**

## 배경

오늘 AI 뉴스레터 흐름은 Claude, Notion, Genspark/OpenClaw 계열처럼 “챗봇 답변”보다 실제 업무툴 안에서 문서·메일·승인·작업을 처리하는 에이전트 흐름이 강했다.

현우님 업무에는 아래 반복 작업이 많다.

- 고객 장애/요청 메일 확인
- 요청 요약 및 심각도 판단
- 고객사별 SR/작업기록 업데이트
- 고객 회신 초안 작성
- 작업 완료 후 보고서 초안 작성

## 1차 자동화 후보

### 고객 메일 → SR 초안

입력:
- 고객 메일 제목/본문
- 고객사명
- 요청 유형: 장애 / 변경 / 점검 / 라이선스 / 일반문의

출력:
- SR 제목
- 고객사
- 요청 요약
- 영향도/긴급도
- 필요한 다음 액션
- 고객 회신 초안
- `maint/Maint/{고객사}/기술지원_요청내역.md`에 넣을 초안

## 운영 원칙

- 외부 발송 전에는 반드시 현우님 확인을 받는다.
- 고객 담당자/내부 IP/계약정보는 보고서 외부 공유 전 마스킹한다.
- 자동화는 “초안 생성”까지만 우선 적용하고, 발송/수정/삭제는 승인 기반으로 처리한다.
