# AI/VDI/공공IT 뉴스 브리핑 규칙

## 목적

Gmail 뉴스레터와 웹 검색 결과를 바탕으로 현우님 사업에 적용 가능한 내용만 선별한다.

## 분류

| 분류 | 설명 |
|---|---|
| 바로 적용 | 현우봇/VDI 업무 자동화에 바로 쓸 수 있음 |
| 사업 아이디어 | 제안서/서비스 패키지로 발전 가능 |
| 기술 추세 | 장기 관찰 필요 |
| 삭제 후보 | 광고/할인/무관한 홍보 |

## 관심 키워드

- AI Agent, automation, workflow, OpenClaw, Claude Code, Manus
- VDI, DaaS, Citrix, Omnissa, VMware, Tilon, KT DaaS
- N2SF, 제로트러스트, NAC, 망분리, 공공기관 보안
- 장애 자동화, 로그 분석, 보고서 자동화, SOC, ISO27001

## 출력 형식

### 오늘 AI/VDI 브리핑

1. 핵심 흐름
2. 중요 뉴스 TOP 3~5
3. 현우님 사업 적용 포인트
4. 읽을 메일 / 삭제할 메일
5. 오늘 바로 해볼 액션 1개
